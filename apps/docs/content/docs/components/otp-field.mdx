`OTPField` is a one-time-code input: a row of single-character slots backed by one hidden input.

<Demo>Typing a 6-digit code.</Demo>

## Anatomy

<Anatomy code={`OTPField.Root
  OTPField.Input (× length)
  OTPField.Separator`} />

`OTPField.Separator` is the standalone `Separator`, re-exported — put one between groups of digits
for a code like `123-456`.

## Usage

The behaviour is headless — the **Code** tab is the component; the **StyleSheet** and **Uniwind** tabs are two ways to design it.

<Tabs items={['Code', 'StyleSheet', 'Uniwind']}>

<Tab value="Code">

```tsx
import { OTPField } from '@limonify/zest-ui';

<OTPField.Root length={6} onValueChange={setCode}>
  {Array.from({ length: 6 }).map((_, i) => (
    <OTPField.Input key={i} index={i} style={(s) => [styles.slot, s.activeIndex === s.index && styles.slotFocused]} />
  ))}
</OTPField.Root>
```

</Tab>

<Tab value="StyleSheet">

```tsx
import { StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  slot: { width: 44, height: 52, borderWidth: 1, borderColor: '#d4d4d4', borderRadius: 10, textAlign: 'center', fontSize: 20 },
  slotFocused: { borderColor: '#4c7a0b' },
});
```

</Tab>

<Tab value="Uniwind">

```tsx
import { clsx } from 'clsx';
import { OTPField } from '@limonify/zest-ui';

<OTPField.Root length={6} onValueChange={setCode}>
  {Array.from({ length: 6 }).map((_, i) => (
    <OTPField.Input
      key={i}
      index={i}
      className={(s) => clsx('h-13 w-11 rounded-lg border text-center text-xl', s.activeIndex === s.index ? 'border-lime-700' : 'border-neutral-300')}
    />
  ))}
</OTPField.Root>
```

</Tab>

</Tabs>

## Accessibility

Set `validationType` to restrict input (numeric/alphabetic). `mask` replaces the visible character while keeping the real value.

The root renders with `role="group"`, so the slots announce as one field rather than as N unrelated
text boxes — pass `accessibilityLabel` on it to name the code being entered. Each slot defaults to
`"Digit 1 of 6"`-style labelling, since every box otherwise looks and reads identically; pass your
own `accessibilityLabel` on a slot to override it.

Inside a [`Field.Root`](/docs/components/field) the field's label and messages attach to the group,
and entering a complete code marks the field dirty, filled and touched.
