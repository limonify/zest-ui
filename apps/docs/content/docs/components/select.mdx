---
title: Select
description: A trigger that opens a list to choose one (or several) values.
---

`Select` shows the chosen label on a trigger and opens an anchored list to pick from. `items` lets `Select.Value` render a label before the popup has ever mounted; set `multiple` for multi-select.

<Demo>Choosing a fruit, and a multi-select.</Demo>

<Callout type="info">
  **Select vs Combobox vs Autocomplete.** Reach for **Select** to pick from a known list with no
  typing; **[Combobox](/docs/components/combobox)** when the user types to filter and choose a bound
  value; **[Autocomplete](/docs/components/autocomplete)** when the typed text itself is the value
  (free-text with suggestions).
</Callout>

`Select.Arrow` points the popup at its trigger and is positioned for you; `Select.Separator` is the
standalone `Separator`, re-exported so a divider between groups reads in the same vocabulary.

## Usage

The behaviour is headless — the **Code** tab is the component; the **StyleSheet** and **Uniwind** tabs are two ways to design it.

import { Select } from '@limonify/zest-ui';

<Select.Root items={FRUITS} value={value} onValueChange={setValue}>
  <Select.Trigger style={styles.trigger}>
    <Select.Value style={styles.text}>{(s) => s.label ?? 'Pick a fruit'}</Select.Value>

## API

`Select` — root props below. Every part also accepts the [common props](/docs/common-props).

<AutoType path="../../packages/zest-ui/src/select/root/SelectRoot.tsx" name="SelectRootProps" />

### Before anything is selected

`Select.Value` takes a `placeholder`, shown while no label is known — which is not only "nothing is
selected": without `items`, the selected label is unknown until the popup has been opened once.
`state.placeholder` says which of the two is on screen, so it can be styled differently.

```tsx
<Select.Value
  placeholder="Pick a fruit"
  style={(state) => [styles.value, state.placeholder && styles.muted]}
/>
```

### Object values

Values are compared with `Object.is`, so an object value only ever matches itself. If `items` is
rebuilt on every render — a plain inline array is — the selection is dropped the moment the
identity changes. `isItemEqualToValue` is how you match by content instead:

```tsx
<Select.Root
  value={selected}
  onValueChange={setSelected}
  isItemEqualToValue={(item, value) => item.id === value.id}
/>
```

It applies everywhere the selection is compared: which item is marked selected, which label
`Select.Value` resolves, and what a `multiple` press toggles. `null` and `undefined` never reach
your comparer, so it does not have to guard against an empty selection.

### Opening it from elsewhere

`Select.createHandle()` connects a root to triggers rendered outside it, and lets you open and
close the popup imperatively:

```tsx
const handle = Select.createHandle<string>();

<Select.Trigger nativeID="font" handle={handle} payload="from-toolbar" />
// …anywhere else in the tree
<Select.Root handle={handle}>
  {(payload) => <Select.Portal>{/* … */}</Select.Portal>}
</Select.Root>

handle.open('font');
```

The popup anchors to whichever trigger the id resolves to, so an imperative open lands in the right
place. A trigger's `payload` reaches the root's children when they are a function.

`actionsRef` gives the same control from inside: `close()` closes with the `imperative-action`
reason, and `unmount()` closes without firing `onOpenChange` — for when your own closing animation
has just finished. Set `disablePointerDismissal` to keep the popup open when a press lands outside
it.


### Sizing the popup to its trigger

The positioner and the popup both publish `triggerWidth` and `triggerHeight` — the trigger's
measured size, and the React Native counterpart of the web's `--anchor-width` CSS variable:

```tsx
<Select.Popup style={(state) => [styles.popup, { minWidth: state.triggerWidth }]} />
```

Both are `undefined` until the trigger has been laid out once.

## Animation

`Select.Popup` publishes `state.transitionStatus`. Keep the portal mounted with `<Portal keepMounted>` and fade it in and out:

```tsx
import Animated, { FadeIn, FadeOut } from 'react-native-reanimated';
import { Select } from '@limonify/zest-ui';

<Select.Popup render={(props) => (
  <Animated.View {...props} entering={FadeIn.duration(120)} exiting={FadeOut.duration(120)} />
)}>
  {/* ... */}
</Select.Popup>
```

See the [Reanimated guide](/docs/guides/animation-reanimated) for the full contract.

## Accessibility

The trigger is `accessibilityRole="combobox"` with `aria-haspopup="listbox"`; items are `role="option"`. In `multiple` mode the popup stays open and `Select.Value` exposes `labels`.
