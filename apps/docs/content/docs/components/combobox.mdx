`Combobox` is a text input paired with a filtered list. Typing filters the items; choosing one
fills the input and closes the list. For free-text suggestions without a bound value, use
[`Autocomplete`](/docs/components/autocomplete), which reuses every combobox part.

## API

`Combobox.Root` — every part also accepts the [common props](/docs/common-props) (`style`/`className` as a value or function of state, `render`, `ref`).

<AutoType path="../../packages/zest-ui/src/combobox/root/ComboboxRoot.tsx" name="ComboboxRootProps" />

Filtering defaults to a locale-aware label match — "resume" finds "Résumé". Pass `filter` to change
it, and build your own predicate with [`useFilter`](/docs/utilities/use-filter).

### Cancelling a change

Every callback receives an event details object alongside the new value. Calling `cancel()` on it
vetoes the change — and because one object is shared across a single interaction, cancelling in
`onValueChange` also stops the list from closing:

```tsx
<Combobox.Root
  onOpenChange={(open, eventDetails) => {
    if (!open && eventDetails.reason === 'outside-press') {
      eventDetails.cancel();
    }
  }}
/>
```

The reasons a combobox reports are `input-press`, `input-change`, `trigger-focus`, `item-press`,
`outside-press`, `escape-key`, `imperative-action` and `none`.

### Opening it from elsewhere

`Combobox.createHandle()` connects a root to an input rendered outside it, and lets you open and
close the list imperatively:

```tsx
const handle = Combobox.createHandle();

<Combobox.Input nativeID="fruit" handle={handle} />
// …anywhere else in the tree
<Combobox.Root handle={handle}>{/* … */}</Combobox.Root>

handle.open('fruit');
handle.close();
```

`actionsRef` is the other half of that: `actionsRef.current.close()` closes with the
`imperative-action` reason, and `unmount()` closes *without* firing `onOpenChange` — which is what
you call once your own closing animation has finished.

### Sizing the popup to its trigger

The positioner and the popup both publish `triggerWidth` and `triggerHeight` — the trigger's
measured size, and the React Native counterpart of the web's `--anchor-width` CSS variable:

```tsx
<Combobox.Popup style={(state) => [styles.popup, { minWidth: state.triggerWidth }]} />
```

Both are `undefined` until the trigger has been laid out once.

## Animation

`Combobox.Popup` publishes `state.transitionStatus`. Keep the portal mounted with `<Portal keepMounted>` and fade the list in and out:

```tsx
import Animated, { FadeIn, FadeOut } from 'react-native-reanimated';
import { Combobox } from '@limonify/zest-ui';

<Combobox.Popup render={(props) => (
  <Animated.View {...props} entering={FadeIn.duration(120)} exiting={FadeOut.duration(120)} />
)}>
  {/* ... */}
</Combobox.Popup>
```

See the [Reanimated guide](/docs/guides/animation-reanimated) for the full contract.

## Accessibility

The input is `accessibilityRole="search"` with `aria-expanded` and `aria-autocomplete="list"`; each
item is `role="option"` with `aria-selected`.
