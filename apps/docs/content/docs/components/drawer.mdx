title: Drawer
description: A dialog that also opens and dismisses by swiping, with snap points.

`Drawer` is a `Dialog` you can swipe away. `Drawer.Popup` publishes `swipeMovement` on state so you drive the transform; `Drawer.SwipeArea` opens it from a screen edge. Optional `snapPoints` make it a bottom sheet. Needs `react-native-gesture-handler`.

`Drawer.Provider`, `Indent` and `IndentBackground` are only for the shrink-back effect below; a
plain drawer is `Drawer.Root` and the portal.

`Drawer.Title` and `Drawer.Description` are the dialog's own parts, re-exported: the title names
the drawer for assistive technology and the description is announced with it.

## Shrinking the app behind it

The iOS-style effect where the app scales back as a sheet comes up. `Drawer.Provider` tracks
whether any drawer under it is open; `Drawer.Indent` wraps your own UI and publishes that, and
`Drawer.IndentBackground` is the surface revealed in the gap the scaled-down app leaves.

Upstream drives this with CSS variables. Following the [animation
contract](/docs/guides/animation-reanimated), zest publishes the numbers and you animate:

```tsx
<Drawer.Provider>
  <Drawer.IndentBackground style={styles.indentBackground} />
  <Drawer.Indent
    style={(state) => [
      styles.app,
      { transform: [{ scale: state.active ? 0.94 : 1 }], borderRadius: state.active ? 16 : 0 },
    ]}
  >
    <App />
  </Drawer.Indent>

  <Drawer.Root>{/* … */}</Drawer.Root>
</Drawer.Provider>
```

<AutoType path="../../packages/zest-ui/src/drawer/indent/DrawerIndent.tsx" name="DrawerIndentState" />

`swipeProgress` is what lets the app scale back *with the finger* as the sheet is swiped away,
rather than snapping when it finally closes. `frontmostHeight` is the popup's measured height, for
an indent that scales in proportion to how tall the sheet is.

Two drawers open at once both count: `active` stays `true` until the last one closes. Without a
`Drawer.Provider` the parts still render, inertly — `active` is always `false`.

This effect assumes the app behind a transparent `Modal` is visible, which is how the backdrop
dimming already works. It has not been verified on a device.

## Animation

`Drawer.Popup` publishes `state.transitionStatus` and, while dragging, `state.swipeMovement`. The swipe-to-dismiss gesture is already built in; for the open/close use a slide preset matching the drawer's side, and fade the backdrop:

```tsx
import Animated, { SlideInDown, SlideOutDown, FadeIn, FadeOut } from 'react-native-reanimated';
import { Drawer } from '@limonify/zest-ui';

<Drawer.Backdrop render={(props) => (
  <Animated.View {...props} entering={FadeIn} exiting={FadeOut} />
)} />
<Drawer.Popup render={(props) => (
  <Animated.View {...props} entering={SlideInDown} exiting={SlideOutDown} />
)}>
  {/* ... */}
</Drawer.Popup>
```

See the [Reanimated guide](/docs/guides/animation-reanimated) for the full contract.

## Accessibility

A bottom sheet is `<Drawer.Root snapPoints={[0.25, 0.5, 0.9]}>`. Swipe dismissal reports the `swipe` reason through `onOpenChange`.
